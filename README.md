# Personal webpage

A small static personal website for CSI205TC Question 2.

- `index.html`: profile introduction and four linked project cards.
- `styles.css`: responsive desktop/mobile layout. No build process or JavaScript dependencies.

Content and project links are adapted from the owner's public Profile README:
https://github.com/catcatcat23/catcatcat23

The original Profile repository contains a README rather than an existing website, so the personal text and project descriptions are reused while the HTML/CSS layout is new. No private repository content is included.

Preview locally with `python -m http.server 8000 --directory Question2` from the coursework directory, then visit http://localhost:8000.

Live website: https://catcatcat23.github.io/

GitHub Pages publishes the main branch at the repository root with HTTPS enforced. The local coursework copy also includes network_test.py, docs/ and evidence/ for the tests and report. Those test artifacts are excluded from this public repository.
